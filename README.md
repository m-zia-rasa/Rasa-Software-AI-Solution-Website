# RASA Software & AI Solutions

Official website for **RASA** — an AI and custom software engineering agency serving Afghan businesses and the global diaspora.

## Features

- Next.js 15, React 19, TypeScript, Tailwind CSS
- English, Dari, and Pashto with RTL support
- Home, portfolio case studies, and contact CTAs
- Dark emerald / amber agency design

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:4028](http://localhost:4028).

On Windows, if the project folder name contains `&`, `npm run dev` still works because scripts call Next.js through Node.

## Scripts

| Command | Purpose |
|---|---|
| `npm run dev` | Development server (port 4028) |
| `npm run build` | Production build |
| `npm run start` | Production server (port 4028) |
| `npm run lint` | ESLint |
